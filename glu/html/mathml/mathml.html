MathML in htmlbag

Every formula below is presentation MathML embedded directly in the HTML source. The htmlbag selector picks up the <math> subtree as foreign content, hands it to the MathML reader, and the math engine renders to a single HList that flows inline with the surrounding text.

Inline math: variables and superscripts

The Pythagorean relation a2 + b2 = c2 holds for every right triangle with legs a, b and hypotenuse c.

Single-character <mi> defaults to italic per the MathML spec; the reader auto-maps a, b, c to U+1D44E ff so the font shows them in the Mathematical Italic alphabet.

Inline math: fractions and roots

The quadratic formula x = -b ± b2 - 4ac 2a solves ax2 +bx+c=0.

Display math: big operators with limits

Gauss famously summed the first n integers:

∑ k=1 n k = n(n+1) 2

display="block" routes through math.DisplayMath, which applies the bigger FractionNumeratorDisplayStyleShiftUp and centres limits above / below the sigma rather than typesetting them as scripts.

Nested scripts and indexed roots

Index-of-summation gymnastics plus an n-th root:

∑ i=1 n xi2 n = σn

Multi-character identifier (function name)

Per the MathML default, multi-character <mi> stays upright — that's how function names render correctly:

d dx sin (x) = cos (x)
