# 04 All four insert classes

A top float, body text, a bottom float and a footnote on one page.
The example shows that the four kinds of content keep their order when
they compete for the same page: top floats, body text, bottom floats,
footnotes.

## Run

```
glu ../foproc.lua 04-float-mixed.fo out=out.pdf
```

Run this inside the directory. It writes `out.pdf`; the directory
ships a copy as `result.pdf`.
